# Система заказов: сайт → оплата → таблица → кухня

Без менеджера и без звонков. Клиент собирает корзину, применяет промокод и платит онлайн. Заказ сам попадает в Google Таблицу и на экран кухни. Оплата курьеру тоже возможна: клиент подтверждает заказ сообщением в мессенджер с кодом.

```
Сайт (GitHub Pages)  ──►  Google Apps Script (Code.gs)  ──►  Google Таблица
   корзина, промокод         пересчитывает цены и итог         Меню · Зоны · Промокоды
   оплата / мессенджер       создаёт платёж ЮKassa             Заказы · Позиции · Кухня · Журнал
        ▲                    проверяет оплату у банка                  │
        └──── статус заказа ◄────────────────────────────── kitchen.html (экран кухни)
                                                             + уведомление в Telegram
```

## Защита от ошибок

| Риск | Защита |
|---|---|
| Цена подменена в браузере | Итог считает только сервер по листу «Меню». Цена из браузера игнорируется |
| «Оплачено», хотя денег нет | Статус «оплачен» ставится только после ответа API ЮKassa (`succeeded` и совпадение суммы). Если клиент не вернулся на сайт, оплату раз в минуту проверяет триггер |
| Сумма чека не равна оплате | Скидка распределяется по позициям в копейках. Тест проверяет 180 комбинаций |
| Двойной заказ, двойной клик | Блокировка на 15 секунд на номер телефона, LockService на запись, ключ идемпотентности = код заказа |
| Промокод «на первый заказ» использован повторно | Колонка «Раз на телефон» = да |
| Чужой человек смотрит экран кухни | Ключ кухни хранится в свойствах скрипта, без ключа экран не открывается |
| Позиция закончилась | «В наличии» = нет: позиция пропадает с сайта, а заказ с ней сервер не примет |
| Брошенная оплата | Через 30 минут (настраивается) статус становится «ОТМЕНЁН» |

## Статусы заказа

`ОЖИДАЕТ ОПЛАТЫ` → `НОВЫЙ` → `ГОТОВИТСЯ` → `ГОТОВ` → `У КУРЬЕРА` → `ДОСТАВЛЕН`

- Оплата курьеру: `НАЛИЧНЫЕ: ПОДТВЕРДИТЬ` → кухня жмёт «Подтвердить» после сообщения клиента → `НОВЫЙ`.
- Неудачная или брошенная оплата: `ОТМЕНЁН`.

Для каждого шага ставится отметка времени. По ним видно, сколько готовили и сколько везли.

## Запуск (один раз, около 20 минут)

1. Создать Google Таблицу, например «Сосед-сан — заказы», на аккаунте владельца кухни.
2. В таблице открыть **Расширения → Apps Script** и вставить содержимое `Code.gs`, заменив пример.
3. В редакторе выбрать функцию `setup` и нажать **Выполнить**, разрешить доступ. Появятся листы с примером меню и зон и ключ кухни.
4. **Настройки проекта → Свойства скрипта** — добавить:
   - `YK_SHOP_ID` и `YK_SECRET` — сначала из **тестового** магазина ЮKassa;
   - `TG_BOT_TOKEN` и `TG_CHAT_ID` — необязательно, нужны для уведомлений кухне в Telegram.

   Значения вводятся только здесь. Не пересылать их в чатах и не класть в репозиторий.
5. **Развернуть → Новое развёртывание → Веб-приложение**:
   - «Выполнять от имени»: *меня*;
   - «Доступ»: *все*.

   Скопировать URL вида `https://script.google.com/macros/s/…/exec`.
6. Вставить этот URL в `assets/config.js` → `API: '…'` и закоммитить.
7. Экран кухни: `…/kitchen.html#k=КЛЮЧ` (ключ — `KITCHEN_KEY` из свойств скрипта). Открыть на планшете кухни один раз: ключ запомнится, из адреса уберётся.
8. Лист «Настройки»:
   - `MODE`: `demo` (оплата имитируется) → `test` (тестовый магазин ЮKassa) → `live`;
   - ссылки на мессенджеры;
   - `OPEN = нет`, чтобы поставить приём на паузу.

После каждой правки `Code.gs` нужно сделать **Развернуть → Управление развёртываниями → Изменить → Новая версия**, иначе сайт продолжит работать на старой.

## Что меняет кухня сама, без программиста

| Что | Где |
|---|---|
| Цены, названия, наличие, хиты | лист «Меню» (`Фото` — имя файла из `img/`) |
| Зоны доставки, минимальный заказ, доставка, время | лист «Зоны» |
| Промокоды (%, ₽, срок, лимит, раз на телефон) | лист «Промокоды» |
| Пауза приёма заказов | «Настройки» → `OPEN` |

Изменения видны на сайте сразу после обновления страницы.

## Проверка без Google

```bash
node backend/test.js          # расчёт заказа, промокоды, чек = оплата (180 комбинаций)
node backend/emulator.js      # запускает настоящий Code.gs на поддельной таблице и ЮKassa: http://localhost:8787
```

## Ограничения (честно)

- Google Apps Script рассчитан на десятки заказов в час, не на тысячи. Для одной кухни этого хватает с запасом. Если когда-нибудь станет мало, логика переносится на нормальный сервер без изменений на сайте.
- Уведомления от ЮKassa (webhook) не используются: Apps Script отвечает на них переадресацией. Вместо этого оплату проверяют возврат клиента на сайт и опрос раз в минуту. В худшем случае заказ попадёт на кухню через минуту после оплаты.
- Возвраты денег делаются вручную в личном кабинете ЮKassa.
