# Google Таблица ТаланД

Таблица: «ТаланД — заказы, кухня, реклама», https://docs.google.com/spreadsheets/d/1KreHPuLXvPze5637xRYEW4lgPI8lLFS9PdYOEhaL1NY/edit

Листы, формулы и оформление уже созданы. Что на каком листе — описано на листе «Как устроено» в самой таблице.

## Как сайт пишет в таблицу

```
браузер → /api/events ┐
заказ создан/оплачен  ├→ база сайта (SiteEvent, SheetOutbox) → раз в 15 с → скрипт таблицы (Code.gs) → листы
смена статуса         ┘
```

- **Заказ.** Отправляется при создании, оплате и каждой смене статуса. Скрипт находит строку по номеру и обновляет её, а время каждого шага ставит в свою колонку.
- **События.** Каждый клик дописывается строкой в лист «События».
- **Если таблица недоступна,** очередь ждёт в базе сайта и досылает потом. Отправленным считается только то, что таблица подтвердила.
- **Формулы** скрипт не трогает: колонки «В выручку», «Дата выручки» и листы «Приход», «Кухня», «Реклама», «Воронка», «Блюда».

## Подключение (один раз, около 10 минут)

1. Открыть таблицу → **Расширения → Apps Script** → вставить содержимое `Code.gs` → сохранить.
2. **Настройки проекта → Свойства скрипта** → добавить `SHEETS_SECRET` — длинную случайную строку. Только сюда и в `.env` сайта, в чат не писать.
3. **Развернуть → Новое развёртывание → Веб-приложение**: «Выполнять от имени» — *меня*, «Доступ» — *все*. Скопировать URL вида `…/exec`.
4. В `.env` сайта:
   - `SHEETS_WEBHOOK_URL` — этот URL;
   - `SHEETS_SECRET` — та же строка, что в свойствах скрипта.

   Затем перезапустить сайт. Пересборка не нужна: это серверные переменные.
5. Проверка: оформить тестовый заказ. Через 15–30 секунд он появится на листах «Заказы», «Позиции», «Кухня», «Приход».

   Состояние очереди видно в ответе `/api/health`: сколько ждёт и когда была последняя отправка. Если очередь растёт, первая причина — неверный ключ или URL.

После правки `Code.gs`: **Развернуть → Управление развёртываниями → Изменить → Новая версия**. URL при этом не меняется.

## Проверка без Google

```bash
node sheets/emulator.js 8790     # настоящий Code.gs на таблице в памяти
# сайту: SHEETS_WEBHOOK_URL=http://127.0.0.1:8790/exec и тот же ключ, что в эмуляторе
curl localhost:8790/__dump       # что легло в листы
```

Проверено:
- полный заказ с онлайн-оплатой, заказ при получении, переходы «на кухне → готов»;
- 27 событий из браузера;
- отключение таблицы: событие ждало в очереди и дошло после включения.

## Ограничения

- Apps Script рассчитан на десятки запросов в минуту. Сайт шлёт пачками по 50, одной кухне хватит с запасом.
- В листе «События» за год наберутся десятки тысяч строк. Когда станет медленно, старые месяцы переносим в архивную таблицу — это задача агента, не владельца.
- Лист «Кухня» показывает телефоны и адреса клиентов. Давать доступ к таблице только тем, кому это нужно для работы.
