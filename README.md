# Прототип сайта доставки суши (рабочее название «Сосед-сан»)

Открыть: `python3 -m http.server 8765` в этой папке → http://localhost:8765/

- Название меняется одной константой `BRAND` в начале `assets/app.js`.
- Зоны, пороги, доставка, время — массив `ZONES` (пример, уточнить с кухней).
- Меню — массив `P` (цены/вес примерные), промокоды — `PROMOS` (рабочий пример ANNINO10 = −10%).
- Корзина хранится в localStorage; оплаты нет, оформление заканчивается экраном «Заказ принят» с циклом:
  онлайн-оплата → сразу на кухню; оплата курьеру → подтверждение менеджером → кухня.
- Фото в img/ сгенерированы для макета, без текста и логотипов.
- Структура типовая для Smartomato: шапка, хиро, преимущества, популярное, каталог с категориями, карточка, корзина, оформление, зоны, отзывы, подвал.
- Скриншоты: screens/ (390px и 1440px).
